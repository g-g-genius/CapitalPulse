## 验证方法

本轮结果：后端 98 项测试通过；前端 TypeScript、Lint、生产构建通过。重启本地后端后，后端健康/雷达接口、前端代理对应接口和首页均返回 HTTP 200；健康接口确认工作进程运行、市场处于休市状态、2026 年日历已维护。

- 后端：在 `backend` 运行 `python -m unittest discover -s tests`。
- 前端：在 `frontend` 运行 `node node_modules/typescript/bin/tsc --noEmit`、`npm run lint`、`npm run build`。
- 运行检查：`/api/health`、`/api/stock-radar`，以及前端 `/api/finance/health`、`/api/finance/stock-radar`。
- `health.data.status = healthy` 表示 API 在运行；判断行情可用性还需查看各数据组件的 `market_status`、源时间及 `last_error`。

## 已知边界与维护

- 实测东方财富列表接口存在 `RemoteProtocolError`（服务器断开连接）；启用/禁用环境代理均可复现。本轮提高失败隔离、数据校验和恢复能力，无法保证公共上游持续可用。当前仍沿用东方财富资金口径，主域与延迟域属于同一供应商。
- 全市场逐页抓取并非同一时刻的原子快照，也不是逐笔行情；页面标注每只股票真实比较间隔。15 秒提醒只在板块和自选股的高频采样满足条件时计算。
- 本轮运行验证在收盘后；盘中全市场覆盖率、连续成功率和实际延迟仍需下个交易时段观察。不能把离线测试通过理解为上游已经恢复稳定。
- 2026 年日历依据 [上海证券交易所公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)。每年更新 `backend/utils/trading_calendar.py`；未维护年份会在健康接口给出警告并按周一至周五判断。
- 若需更快、有服务保障的全市场资金异动，仍需接入经过授权且资金指标定义一致的数据源；本轮没有新增付费订阅。
